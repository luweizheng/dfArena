## Context

Standardize two weather-forecast extracts (hourly and daily) into one unified table with consistent fields.

## Requirements

- Input the data
- Output the data

## Output

Each row represents one forecast entry. Use the exact Forecast Type labels `Next 5 Hours` and `Next 5 Days`.

- output_01.csv
  - 6 fields:
    - Forecast Type
    - Date or Time
    - Temperature
    - Max Temp
    - Min Temp
    - Precipitation Chance
