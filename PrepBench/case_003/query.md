## Context
You work for a mobile / cell phone company. You boss asks you to pull together the revenue report of your current batch of contracts (sadly there are only four contracts!). They need to know how much revenue is generated each month from these contracts whilst they are 'live' (ie from their start date until 'x' months in the future when the contract runs out). The aim is to prepare the monthly revenue data using a DataFrame library.

## Requirements

- Input the data
- Import the file
- Make sure you use both input files
- Use one input file to help you create a row of data for each month the person's contract is 'live' for
- Remove unnecessary fields of data
- Output for use within a DataFrame workflow
- Output the data

## Output

- output_01.csv
  - 5 fields:
    - Payment Date
    - Name
    - Monthly Cost
    - Contract Length (months)
    - Start Date
