## Requirements

- Input the data (all six files)
- Form a Date using the file number as a month
- Categorise Product Types as Fruit or Non-Fruit
- Form your % Return Rates for:
  - The full data set
  - Month of Trading
  - Product Type
  - Fruit / Non-Fruit Scents
- Calculate `% Returned` as `(Returned Orders / Total Orders) * 100` and round it to 1 decimal place.
- Create one output table
- Output the data

## Output

- output_01.csv
  - 4 fields:
    - Returned Orders
    - Total Orders
    - % Returned
    - Type
