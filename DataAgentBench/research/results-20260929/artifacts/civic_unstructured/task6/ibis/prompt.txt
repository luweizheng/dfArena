## Data description (context/description.md)

# civic_unstructured

The original data groups are exposed as local Parquet tables.

Original group names are retained below to interpret the original hints. Paths are relative to this dataset directory.

1. civic_docs_database
   - This database is provided as a Parquet table and contains Malibu city council meeting agendas.
   - This database consists of one collection:
     - civic_docs
       - This collection contains 19 documents, one per city council meeting agenda. Each document covers multiple civic projects and their current status at the time of the meeting.
       - Fields:
         - _id (string): Original MongoDB ObjectId encoded reversibly as 24 lowercase hexadecimal characters; not a new identifier
         - report_id (str): Sequential report identifier (e.g., "rid_0001", "rid_0002", ..., "rid_0019")
         - report_content (str): Full plain-text content of the meeting agenda, describing multiple civic projects.

2. funding_database
   - This database is provided as a Parquet table and contains structured funding records for civic projects.
   - This database consists of one table:
     - Funding
       - This table contains funding grant records.
       - Fields:
         - fid (str): Unique funding record identifier
         - project_name (str): Name of the project receiving the grant
         - funding_source (str): Source of the funding
         - grant_time (str): Date the funding was granted
         - amount (int): Funding amount in USD

Each original agenda remains one complete text cell. No project extraction, name matching, status labeling, date correction, noise removal, or funding aggregation is performed. These operations remain part of solving the original tasks.

## Hints and task-specific clarifications (context/hints.md)

# Hints

- Projects have two types: "capital" and "disaster".
- Projects have four statuses: "design", "construction", "completed", and "not started".
- A project's status is the status category of the report section in which it appears. If the narrative update describes a different stage, use the section's status category.
- The same project may appear under different names, so entity resolution is required.
  - Two names likely refer to the same project if their names or agenda descriptions are semantically similar.
  - Two names listed separately in the same agenda are likely distinct projects, as a project usually appears once per agenda.
- For Annual Street Maintenance, the year in the name identifies an annual cycle of the same ongoing project rather than a separate project. Combine this project's records across years, then apply the time range specified in each question to determine status changes and aggregate funding.
- For Storm Drain Trash Screens, treat "Storm Drain Trash Screens" and "Storm Drain Trash Screens Phase Two" as phases of the same project rather than separate projects. Combine their records, then determine status and aggregate funding using the dates specified in each question.
- Some Funding records have a project_name that is not a real civic project; treat these as noise.
- An agenda's stated meeting date may be wrong, so cross-check it against the dates its own text mentions.
- According to the official complete meeting agenda, the meeting date for report rid_0010 is January 26, 2022; the date in the report header is incorrect.
